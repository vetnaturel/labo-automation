Comment connecter un formulaire de site à Notion via Make

Notion est un outil extraordinaire pour centraliser des données, mais y recopier manuellement les messages reçus depuis un formulaire de contact est une perte de temps. Dans ce guide complet, découvrez comment automatiser la réception de vos prospects directement dans votre base de données Notion.

💡 Pourquoi utiliser cette méthode ?

En centralisant vos demandes clients directement dans Notion, vous pouvez leur attribuer un statut (En cours, Traité), ajouter des notes et collaborer en équipe sans jamais ouvrir votre boîte mail.

Étape 1 : Préparer la base de données dans Notion

Ouvrez votre espace Notion et créez une nouvelle page sous forme de Tableau (Database). Ajoutez les colonnes suivantes :

  1. Nom (colonne de type texte par défaut)
  2. Email (colonne de type Email)
  3. Message (colonne de type texte brut)

Étape 2 : Créer le Webhook de réception sur Make

Un Webhook est une URL spéciale capable de "recevoir" des informations instantanément dès qu'un formulaire est validé :

  1. Sur votre tableau de bord Make, créez un nouveau scénario.
  2. Sélectionnez le module Webhooks et choisissez l'action Custom Webhook.
  3. Cliquez sur "Add" pour générer une URL unique. Copiez cette URL et collez-la dans les réglages de votre outil de formulaire (Typeform, Elementor, Tally, etc.).

Étape 3 : Configurer l'action d'enregistrement dans Notion

Une fois que Make intercepte les données du formulaire, il doit les envoyer au bon endroit :

  1. Ajoutez un second module à votre scénario et cherchez Notion.
  2. Sélectionnez l'action Create a Database Item (Créer un élément de base de données).
  3. Connectez votre compte Notion et donnez l'autorisation d'accéder à la page créée à l'étape 1.
  4. Liez les champs : faites glisser la donnée du formulaire Prénom/Nom dans la case "Nom" de Notion, et faites de même pour l'adresse e-mail et le contenu du texte.

Étape 4 : Activation et test en conditions réelles

Activez votre scénario sur Make en basculant l'interrupteur sur ON. Allez sur votre site internet et soumettez un faux message dans votre formulaire. Ouvrez votre page Notion : une nouvelle ligne vient de se créer instantanément avec toutes les informations saisies ! Vous venez de créer un CRM automatisé et gratuit.
