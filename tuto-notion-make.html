Tutoriel : Connecter un formulaire web à Notion avec Make

Apprenez à centraliser automatiquement les soumissions de vos formulaires dans une base de données Notion en moins de 10 minutes.

Étape 1 : Préparer votre compte Make

Pour commencer, créez un compte gratuit sur Make si ce n'est pas déjà fait. L'offre gratuite suffit largement pour ce projet.

Créer un compte Make gratuit

Étape 2 : Configurer le Webhook

Dans votre tableau de bord Make, créez un nouveau scénario et ajoutez un module Webhooks. Ce webhook servira à recevoir les réponses envoyées depuis votre formulaire.

Étape 3 : Relier à Notion

Ajoutez un second module Notion (Create a Database Item). Connectez votre espace Notion puis mappez les champs de votre formulaire avec les colonnes de votre table Notion.

Étape 4 : Activer l'automatisation

Lancez un test pour vérifier que la donnée arrive correctement dans Notion, puis basculez votre scénario sur ON pour qu'il fonctionne en continu.
